1. Tối Ưu Phong Cách Trả Lời: Đi Thẳng Vào Trọng Tâm

Trước đây khi hỏi "doanh thu tháng nào đang là lỗ nhất, tại sao...", AI có xu hướng dạo đầu chào hỏi dài dòng, liệt kê lại phép tính của tất cả các tháng rồi mới nói rằng thực tế không có tháng nào lỗ. Code đã được tinh chỉnh theo nguyên tắc Trả lời trực diện (BLUF - Bottom Line Up Front):

3 quy tắc cốt lõi đã nạp cho AI:
1. Trả lời thẳng vào câu hỏi ngay ở câu đầu tiên, bỏ toàn bộ văn mẫu chào hỏi lan man.
2. Đính chính ngay nếu câu hỏi sai sự thật: Nếu người dùng hỏi tháng nào lỗ nhất trong khi hệ thống không có tháng nào lỗ, AI khẳng định ngay: "Hiện tại hệ thống không có tháng nào bị lỗ...", sau đó chỉ ra tháng có lợi nhuận thấp nhất.
3. Súc tích: Tóm tắt nguyên nhân bằng 2 gạch đầu dòng rõ ràng thay vì viết bài luận dài.

Kết quả phản hồi thực tế sau khi tối ưu:

👤 Người dùng: "doanh thu tháng nào đang là lỗ nhất, tại sao, do đâu mà lỗ"

🤖 Trợ lý AI NDA HOME:

"Hiện tại hệ thống không có tháng nào bị lỗ; tất cả các tháng (tháng 9, tháng 10 và tháng 11) đều đạt lợi nhuận dương.

Tháng có lợi nhuận thấp nhất là tháng 11/2026 (tính đến thời điểm hiện tại), với các lý do chính sau:
• Thời gian chưa kết thúc: Dữ liệu tháng 11 mới chỉ ghi nhận đến ngày 18/11, chưa bao gồm các khoản thu cuối tháng thường thấy.
• Chi phí vận hành tập trung: Phát sinh các khoản chi phí lớn ngay đầu tháng như lương nhân sự (24.000.000 ₫) và tiền thuê văn phòng (15.000.000 ₫), tạo áp lực chi phí ngắn hạn cao hơn so với các tháng trước đó."

2. Backend Rút Gọn Chuẩn Sinh Viên Năm 3 (50 Dòng Code)

Toàn bộ code tại app/api/chat/route.ts đã được đơn giản hóa tối đa, chỉ gồm 5 bước tuần tự rất dễ hiểu:

import { NextResponse } from "next/server";
import { prisma } from "@/lib/prisma";
import { GoogleGenAI } from "@google/genai";

// Khởi tạo Gemini AI từ file .env
const ai = new GoogleGenAI({
  apiKey: process.env.GEMINI_API_KEY,
});

export async function POST(request: Request) {
  try {
    // 1. Nhận tin nhắn từ client gửi lên
    const { message } = await request.json();

    // 2. Lấy dữ liệu thật từ Database PostgreSQL qua Prisma
    const transactions = await prisma.transaction.findMany({
      orderBy: { date: "desc" },
    });

    // 3. Soạn prompt kèm dữ liệu thật và quy tắc trả lời
    const prompt = `
Bạn là Trợ lý AI Quản lý Tài chính cho hệ thống NDA HOME.
Dưới đây là TOÀN BỘ dữ liệu giao dịch thực tế lấy từ Database:
${JSON.stringify(transactions, null, 2)}

YÊU CẦU:
- Trả lời bằng tiếng Việt thân thiện, rõ ràng, có định dạng số tiền ₫.
- Dựa CHÍNH XÁC vào dữ liệu ở trên để tính toán thu chi.
- Nếu câu hỏi ngoài phạm vi (thời tiết, nấu ăn...), hãy lịch sự giải thích mình là Trợ lý Tài chính và điều hướng về thu chi.

Câu hỏi của người dùng: "${message}"
`;

    // 4. Gọi Gemini AI sinh câu trả lời
    const response = await ai.models.generateContent({
      model: "gemini-3.1-flash-lite",
      contents: prompt,
    });

    // 5. Trả kết quả JSON về giao diện
    return NextResponse.json({ reply: response.text });
  } catch (error) {
    return NextResponse.json({ error: "Lỗi xử lý AI" }, { status: 500 });
  }
}

3. Giao Diện Chatbox Tại app/components/AIChatBox.tsx

  • Dùng các React hook cơ bản: useState, useRef, useEffect.
  • Hàm gửi tin nhắn handleSend() đơn giản, gọi HTTP POST tới /api/chat.
  • Thông báo lỗi thân thiện khi rớt mạng: "⚠️ Hiện tại kết nối đến AI đang bận hoặc gián đoạn. Bạn vui lòng thử lại sau giây lát nhé!".
